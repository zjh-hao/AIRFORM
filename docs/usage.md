# 使用工坊

从根目录 AIRFORM.html 进入。「选择特效」和「特效目录」打开同一目录。选择后可在「工坊设置」切换普通摄像头或 Astra，再启动输入。

- **绘画**：张开右手解锁，捏住拇指和食指移动以绘制，松开结束。拖动画布查看三维笔迹。没有相机时可用鼠标试画或播放设置中的合成样例。
- **掌上全息**：选择内置素材或把文件拖进「自定义素材」。GLB 需内嵌几何与贴图。WebP 可选择普通图片、动图或 8×8 动画图集。调整为 25%–200% 后应用，平摊任意一只手。导入文件仅在当前页面内使用。
- **导出**：空间绘画可撤销、重做、清空，或导出笔迹。PNG、JSON 和 GLB 面向绘画作品，实景全息预览属于相机叠加层。
- **回放**：`research-data/sample/synthetic-hand.json` 可从设置的实验回放入口载入。回放会停止相机、替换当前画布，已有作品可先导出。
- **停止**：用「停止输入」释放相机。Astra 取流问题可运行安装说明中的诊断工具。
